# 云石天宫

一个纯静态、免部署的微博式动态广场。打开即用，数据自动保存在浏览器本地存储中。

## ✨ 功能特性

- 📝 **发布动态** — 支持昵称、文字内容、emoji 快捷插入
- ❤️ **点赞** — 点击即赞，每人每动态限一次
- 💬 **评论** — 每条动态下可展开评论并回复
- 🔍 **搜索** — 按内容或昵称快速查找动态
- 🌓 **暗色模式** — 一键切换主题
- 🔐 **管理员模式** — 密码保护，支持内容编辑、数据导入导出、删除管理

## 🚀 使用方式

### 方式一：直接打开（推荐）

双击 `index.html` 即可在浏览器中使用，无需任何安装或服务器。

### 方式二：本地预览（可选）

```bash
npx serve . -s -l 3000
```

然后访问 `http://localhost:3000`。

### 方式三：静态托管

将以下文件上传至任意静态托管服务（GitHub Pages、Vercel、Cloudflare Pages 等）即可：

```
index.html
styles.css
app.js
```

## 🔐 管理员

点击右上角 ⚙️ 进入管理员登录，默认密码为 `admin`。登录后可：

- 直接点击页面上的 ✎ 标记编辑文字内容（标题、副标题、品牌名等）
- 删除任意动态或评论
- 导出 / 导入全部数据（JSON 格式）
- 修改管理员密码

## ⚠️ 数据说明

所有数据存储在浏览器的 `localStorage` 中，**清理浏览器数据会导致内容丢失**。建议定期通过管理员面板「导出数据」备份。

## 🛠 技术栈

- 纯原生 HTML / CSS / JavaScript
- 无任何框架或构建工具依赖
- 无后端，数据持久化通过 `localStorage`
